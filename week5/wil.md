- Fetch Join: 1개 -> 1개
- Batch Size: 2개 -> 3개

```
- Fetch Join은 특정 조회단계에서 관련 데이터를 함께 join하여 한번에 조회하는 것으로, 주문수가 늘어나도 SQL 개수는 동일하게 1개로 유지된다.
- Batch Size는 여러건의 추가 조회를 IN 조건으로 함께 묶어서 조회하는 것으로, batch size=10으로 정해놨기에 추가적으로 SQL이 기존보다 1개 
  더 늘어났다.
```

1. 쿼리 튜닝은 어떤 문제를 해결하기 위한 작업인가요?

- 쿼리튜닝은 SQL 데이터를 참조/편집할 때 관련 작업에 소요되는 메모리와 시간을 효율적으로 관리하기 위한 작업이다.  

2. SQL 개수를 줄이는 것 외에 어떤 점을 확인할 수 있을까요?

- 실행계획; 즉 컴퓨터가 참조하는 방식을 따라가며 최소화 할 수 있는 방안을 찾는다.
- 인덱스; 더 효율적인 인덱스, 즉 명령어가 있는지 찾는다.
- 페이징; 더 효율적으로 데이터를 검색하는 방법을 찾는다.
