1. Dockerfile, 이미지, 컨테이너는 각각 어떤 역할을 하나요?

이미지: 어플리케이션을 실행하는데 필요한 것들의 묶음  
-> c언어에서의 솔루션, 파이썬에서의 모듈 묶음이 이에 해당하지 않을까 생각
Dockerfile: 이미지를 만들기 위한 파일의 집합체  
컨테이너: 이미지를 통해서 만들어진 인스턴스

2. AWS와 EC2는 각각 무엇인가요?
AWS: 항시 서버용 컴퓨터를 켜 둘 수 없기에 아마존이 마련해준 클라우드 서버 서비스  
EC2: AWS가 만든 가상 서버

3. 외부에서 EC2에 배포한 API를 호출할 때, IP 주소와 포트는 어떤 역할을 하나요?
IP는 인터넷에서 해당 서비스가 위치한 주소를 의미하며, 포트는 들어오는 문(출입구 번호)를 나타낸다.


실제 서비스를 운영할 때 서버 외에 어떤 것들이 필요할까요?  
>> 저장소(데이터 베이스), 도메인(주소의 닉네임), Https(보안인증서 등이 필요하다.)

사용자가 많아져 서버 한 대로 요청을 감당하기 어려워진다면 어떻게 할 수 있을까요?
>> 로드 밸런서(서버 여러대로 부하를 분산시키기), 오토 스케일링(자동적으로 트래픽이 많이 생기는 시간대를 파악, 시간에 맞게 서버 수를 유동적으로 조절)

이번 실습에서 사용한 EC2 외에, 애플리케이션을 배포할 수 있는 다른 방법에는 무엇이 있을까요?
>>AWS Elastic Beanstalk, 컨테이너 관리 서비스 (ECS, EKS), 서버리스 (AWS Lambda 등);함수만 올려놔서 효율적 운영
